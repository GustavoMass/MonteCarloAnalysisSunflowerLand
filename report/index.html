Run it yourself

  1. Install Python 3.10 or newer from python.org (tick “Add python.exe to PATH”). Nothing else is needed.
  2. Double-click run.bat in the project folder, or type python run.py. It pulls your farm, the board, delivery orders, flower recipes, NFT floors and P2P prices from sfl-manager, simulates (about 3 minutes) and opens this report.
  3. Change your habits in config.json: tax, skill builds, building levels per week, herd buffer, pig policy, NPC delivery frequency, board shares, boosts to test. Use --quick while experimenting.
  4. From 9 Nov the board shows real ticket amounts; every run picks them up and replaces the guesses. Each run also stores the ticket NPC orders it sees in Data/ticket_orders_history.json, so Raven's flower requests build up week by week.
python run.py            # refresh + simulate + open
python run.py --quick    # fast, fewer runs
python run.py --offline  # reuse saved data
python -m unittest discover -s tests -t .
