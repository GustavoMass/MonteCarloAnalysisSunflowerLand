Every level, every animal: the Monte Carlo spread

Each bar is one level. The pale bar covers 80% of simulated runs (P10–P90), the solid bar the middle half (P25–P75), the white tick the median. The spread comes from which tool each pet asks for: two Music Boxes can finish a level on pets alone, two Petting Hands leave it to the feed.

Run it yourself

  1. Install Python 3.10 or newer from python.org (tick “Add to PATH”). Nothing else is needed.
  2. Open the project folder and double-click run.bat, or in a terminal type python run.py. It pulls your farm, the bounty board and P2P prices from sfl-manager, runs the simulation and opens this report.
  3. Change your habits in config.json: tax, skill builds to compare, barn levels, delivery frequency per NPC, ticket base per bounty. Run again.
  4. After 9 Nov the board shows ticket bounties; the next run picks them up automatically and replaces the guessed ticket numbers.
python run.py            # refresh + simulate + open
python run.py --offline  # reuse saved data
python -m unittest discover -s tests -t .
